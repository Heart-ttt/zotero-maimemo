# 开放 API 实测记录

历史记录说明（2026-10-04）：当前需求已改为只加入单词，见 [SCOPE.md](SCOPE.md)。本文保留当时的实测与接口调研；例句相关接口、配额和未验证项不再是当前功能或开发前提。

2026-09-21。目的：核对非官方 SDK 文档的路径，摸清 token 失效行为。token 有效，云词本为空（本账号还没建过）。

token 本身不入库，下面命令用环境变量 `$TOK` 占位。

## base URL

官方文档的 curl 示例写的是 `https://open.maimemo.com/open/api/v1/phrases`。非官方 SDK 文档只写相对路径 `/api/v1/...`，容易误拼。

```bash
curl -s -w "%{http_code}" -H "Authorization: Bearer $TOK" \
  'https://open.maimemo.com/open/api/v1/notepads?limit=3&offset=0'
# 200  {"errors":[],"data":{"notepads":[]},"success":true}

curl -s -w "%{http_code}" -H "Authorization: Bearer $TOK" \
  'https://open.maimemo.com/api/v1/notepads?limit=3'
# 200  <!doctype html> ... 打到 SPA 首页
```

第二条是坑：状态码也是 200，只有 body 是 HTML。客户端必须校验 content-type 或 `success` 字段，不能只看 HTTP 码。

## 接口清单

路径与用途，2026-09-21 核对。官方文档是 [Stoplight 渲染的 SPA](https://open.maimemo.com/#/)，WebFetch 抓不到正文，要用浏览器读。

| 接口 | 路径 | 用途 |
|---|---|---|
| 云词本 | `/open/api/v1/notepads` | 增删改查，content 支持 `#章节` 和 `//整句`（服务端自动还原词形） |
| 例句 | `/open/api/v1/phrases` | 字段 `voc_id` `phrase` `interpretation` `tags` `origin` |
| 释义 | `/open/api/v1/interpretations` | `voc_id` `interpretation` `tags` `status` |
| 助记 | `/open/api/v1/notes` | 完整 CRUD |
| 学习数据 | `/open/api/v1/study/*` | 公测。今日进度、今日词表、学习记录查询、加词进计划 |
| 记忆卡 | Markji 系列 schema | 见文末 |

字段名注意：非官方 SDK 文档里写的是驼峰 `vocId`，那是它 TypeScript 方法的参数名；实际 wire 格式是下划线 `voc_id`，而且创建例句要包一层 —— `{"phrase":{"voc_id":...}}`。SDK 源码里还记了一条：创建成功可能返回 201 而不是 200。

## token 形态

43 字符，无点分段，不是 JWT。过期时间解不出来，只能靠调用结果判断。

两个来源，寿命不同：

- App 内「我的 → 更多设置 → 实验功能 → 开放 API」。相对长期，插件应该用这个。
- 网页端 `/open/api/v1/tokens/openapi`。靠浏览器 cookie 会话签发，hover-translate 的 README 记的是 24 小时过期。

## 有没有 refresh

没有。

```bash
curl -s -w "%{http_code}" 'https://open.maimemo.com/open/api/v1/tokens/openapi'
# 302

curl -s -w "%{http_code}" -H "Authorization: Bearer $TOK" \
  'https://open.maimemo.com/open/api/v1/tokens/openapi'
# 302
```

带不带 Bearer 都是 302 跳登录，说明这个端点认的是浏览器 cookie 会话，不认 Bearer。旧 token 换新 token 没有通路。

## 失效长什么样

```bash
curl -s -H "Authorization: Bearer invalid_token_probe" \
  'https://open.maimemo.com/open/api/v1/notepads?limit=1'
# 401 {"errors":[{"code":"common_unauthorized","msg":"Authorization failed","info":""}],"success":false}
```

`common_unauthorized` 是唯一可靠的失效信号，插件的重试与提示逻辑挂在这个 code 上。

## 文档里之前没查到的

- 内容创建配额：每天 600 条，例句 + 助记 + 释义合并计算。官方原文还带一句低质内容会被进一步限制。
- 频控三层：10s / 20 次，60s / 40 次，5h / 2000 次（墨墨背单词）；墨墨记忆卡那一层是 5h / 8000 次。超限返回 429。
- 墨墨记忆卡（Markji）跟背单词共用这套 API，schema 有 `MarkjiRootDeck` `MarkjiDeck` `MarkjiChapterset` `MarkjiChapter` `MarkjiCard` `MarkjiFolder` `MarkjiFile`。卡片有自己一套标记语法：挖空 `[F#1#内容]`、选择题 `[Choice#multi#...]`、LaTeX 公式 `[E##a^2+b^2=c^2]`，还支持图片、音频、卡片互链、文字样式。读论文场景里这块比背单词值钱 —— 公式、定义、方法步骤做成挖空卡或选择题，是单词本装不下的。第一版不碰，但架构别锁死在 notepad 上。
