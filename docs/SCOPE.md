# 范围：V1 做什么

2026-09-21 初定，2026-10-04 更新：只加入单词，取消例句功能；2026-10-04 再次更新：移除阅读时提示在背的词。本项目只做墨墨背单词和 Zotero 的联动。本文是当前功能范围，后续决策直接更新这里。

2026-10-05 接入阅读器弹窗、设置页、本地持久化和后台同步，并生成 Zotero 10.x 安装包。本文中的自动词形还原、词义查询、清空与撤销仍为后续 V1 目标；具体完成情况见 [HANDOFF.md](HANDOFF.md)。当前以原文词作为原形初值，支持手动修改，加入后在原生弹窗中显示确认结果。

## 目标

在 Zotero 阅读论文时划选生词，点「加入」，将单词保存到本地队列，再后台统一加入墨墨云词本 **「Zotero 背诵」** 和学习计划。

本地单词库保存加入记录与同步进度。选区只用于确定目标单词，不保存、生成、翻译或同步例句。

## 产品边界

本项目只支持 **Zotero ↔ 墨墨背单词**。不接入欧路词典、扇贝单词、Anki、Quizlet、本地 CSV 或其他单词软件，也不提供通用的多平台适配层。竞品调研中出现的其他平台仅用于理解现有 Zotero 插件的功能边界，不属于本项目目标。

## 已定的决策

- 取词入口是阅读中即时划词，不要求先创建 Zotero 注释。
- 检查并参考 [zotero-plugin-template](https://github.com/windingwind/zotero-plugin-template) 的生命周期职责分离，自行实现最小插件入口。竞品只提供交互和架构参考，不 fork hover-translate；检查记录见架构文档。
- 点「加入」才保存；划词本身只展示弹窗，不自动入队。
- 所有单词统一写入墨墨云词本「Zotero 背诵」，不提供词本分流或其他目标词本配置。这里的「Zotero 背诵」就是本项目使用的云词库。
- 加入学习计划默认开启，可在设置中关闭。
- 不采集、存储或写入作者、年份、标题、DOI、页码和 `zotero://` 深链。

## 划词与加入

支持双击单词或拖选文本。选区只有一个词时直接使用该词；包含多个词时，在弹窗中列出可点击的词，由用户选一个加入。一次只加入一个词，不保存其余选区文本。

一次完整操作：

1. 在 PDF 里选中文字，Zotero 原生的选中弹窗出现。通过官方 `renderTextSelectionPopup` 钩子追加插件区域。
2. 确定目标单词，进行词形还原并查询词条与释义。这一步只发查询请求，不写入本地加入记录或墨墨账号；查询仍计入接口频率限制。
3. 弹窗显示可编辑的原形、只读的词义、墨墨词库是否收录，以及是否已入队或已同步。词形还原错误时可以当场修改，例如将 `mice` 改为 `mouse`。
4. 点「加入」，写入本地队列，给出确认提示并关闭弹窗。
5. 未点「加入」就关闭弹窗、按 Esc 或重新划选，不产生加入记录。

判重按原形进行，例如 `attenuated` 和 `attenuates` 算同一个词。已加入的词显示「已在队列」或「已同步」，加入按钮置灰；失败或部分同步的记录从管理面板重试。

词库未收录的词明确提示「墨墨词库未收录，可能无法加入学习计划」。用户仍可保存到本地，并尝试写入云词本；界面应区分本地已保存、词本已写入和学习计划已加入，不能把查不到的词标成已进入学习计划。具体词本处理行为需要实测。

弹窗沿用 Zotero 的出现和关闭规则，不修改原生颜色、高亮或下划线区域。监听器需防止插件升级后重复注册，禁用或卸载时解除。

## 本地记录与同步状态

「加入」指写入本地队列，「同步」指后台写入墨墨。未点加入时，目标单词只在弹窗内存中。

一条加入记录包含：

- `lemma`：词形还原后的原形，用于查询、判重和推送。
- `surface`：选中的目标词在原文里的形态，仅保存这个词。
- `notepadId`：统一目标云词本的 ID，由设置或启动时按名称解析得到。
- `status`：`queued`、`partial`、`synced` 或 `failed`。
- `inNotepad`：统一目标云词本中是否已写入。
- `inStudyPlan`：是否已加入学习计划。

记录不包含句子、句子翻译或例句 ID。

云词本写入和学习计划加入是两步独立操作。第一步成功、第二步失败时标记为 `partial`，重试只补未完成的步骤。关闭加入学习计划时，成功写入词本即可标记为 `synced`。词库未收录等无法继续的情况须说明原因，不无限自动重试。

本地进度持久化，断网、退出或重启后可以继续。云词本 ID 标识整个词本，不是单词级 ID；重试前需核对词本内容，防止上次已写入但本地尚未记录成功而重复追加。

## 后台推送

加入时先落本地，后台消费队列，默认依次完成：

1. 通过 `notepads` 将单词追加到统一目标云词本。
2. 通过 `study/add_words` 将单词加入学习计划；设置关闭时跳过此步。

对用户只提供增量追加，不提供整本覆盖模式。若接口更新必须提交整个 `content`，先读取已有内容再合并，保留用户原有单词、章节和其他内容；具体更新方式以及冲突处理需要验证。

所有查询和写入共享限速器。已记录的频控为 10 秒 20 次、60 秒 40 次、5 小时 2000 次；遇到 429 时延迟重试，面板显示等待原因。

此前记录的每日 600 条配额针对例句、助记和释义的内容创建。当前流程不创建这些内容，不再预设每日最多加入 600 个单词，也不设置例句创建配额计数。`notepads` 和 `study/add_words` 是否另有限额仍需实测，确认后再纳入调度。

收到 401 且错误码为 `common_unauthorized` 时暂停队列，在设置或管理面板提示重新填写 token，不在阅读中途弹窗打断。恢复认证后继续未完成步骤。

## token 与设置

使用墨墨 App 内「我的 → 更多设置 → 实验功能 → 开放 API」提供的长期 token，在插件设置中填写。

token 不以明文写入 Zotero prefs，不进入日志或导出数据。2026-10-05 已采用 Zotero 凭据管理器的独立认证域保存，设置页支持保存、留空保留、清除和只读测试连接。墨墨没有已验证的 refresh token 通路，失效后由用户重新填写。

设置提供 token 配置和「自动加入学习计划」开关。

## 管理面板与撤销

显示待同步、部分成功、同步失败和已同步记录，以及限流等待或认证暂停状态。支持重试失败步骤、移除待同步记录和一键清空待同步队列。

- 同步前撤销：移除本地待同步记录，不写墨墨。
- 同步后撤销：从统一目标云词本中移除插件新增的词，保留其他内容。若词在同步前已经存在，不删除原有词。实现时需记录是否由插件新增。

云词本撤销不自动撤回学习计划中的单词，操作前说明这一边界。学习计划移除接口及其语义尚未验证，不纳入 V1 的撤销承诺。

## V1 不做

- 例句生成、原句捕获、句子编辑、整句翻译和例句同步，不调用 `phrases`。
- 文献出处与回跳原文链接。
- 打开文章时扫描全文并提示正在背的词。
- 一次加入多个词、批量回灌历史文献。
- 停用词与 AWL 词表分级过滤。
- 创建释义 `interpretations` 或助记 `notes`。
- 从墨墨反向同步单词记录回 Zotero。
- 墨墨记忆卡 Markji。

## 开发前待确认

1. **单词写入链路**：云词本创建、读取、合并更新是否可用；已有词和未收录词如何处理；加入学习计划后是否能在 App 确认，重复加入有何结果。
2. **词义来源**：`GET /interpretations?voc_id=` 是否提供词典释义，还是只提供用户自建释义。不可用时需确定可用的只读词典方案。
3. **词形还原**：评估词典查表、轻量还原库等浏览器环境方案。
4. **原生运行验证**：当前包只声明支持 Zotero 10.x，已核对 10.0.5 官方源码；仍需实测阅读器和设置页。单词记录用原子 JSON 文件，token 用独立凭据存储。
5. **目标词本验证**：已经实现按名称解析「Zotero 背诵」的 ID；找不到或同名多个时暂停并提示，不静默写入其他词本，不自动创建。

词库收录率仍需要测试，用于说明能加入学习计划的范围；例句创建权限、长度、翻译字段和 App 例句显示不再是开发前提。

## 阅读器接入依据

2026-09-21 的源码调研记录指向 Zotero master 分支 `chrome/content/zotero/xpcom/reader.js:2698-2760`，提供如下钩子：

```javascript
Zotero.Reader.registerEventListener('renderTextSelectionPopup', (event) => {
  const { reader, doc, params, append } = event;
  // params.annotation.text 是本次选中的文本，仅用于确定目标单词。
  append(myButton);
}, 'wordsync@example.com');
```

事件提供 `reader`、`doc`、`params` 和 `append`，可向原生选中弹窗追加插件区域。禁用或卸载时按插件 ID 清理，也可调用 `unregisterEventListener`。当前已对照本机 Zotero 10.0.5 的源码核对该钩子与注销接口，原生运行效果尚待验证；不声明 Zotero 8 / 9 兼容。

## 做完的标准

1. PDF 里划一个词，弹窗显示原形、词义和加入状态；未点加入时不产生本地加入记录或墨墨写入。
2. 点「加入」后出现一条单词记录；多词选区中只保存用户选中的一个词，不保存句子。
3. 同一个词的不同形态按原形判重，已入队或已同步时无法重复加入。
4. 同步后能在对应云词本看到单词；自动加入学习计划开启时，墨墨 App 中该词已进入学习计划，关闭时只写词本。
5. 写入保留云词本的原有内容；部分成功后只重试未完成步骤，重启后不重复追加。
6. 断网、429 或 token 失效时不丢记录，恢复后可以继续。
7. 管理面板能查看进度、重试、清空待同步队列和撤销；撤销不误删原有词。
8. 连续正常使用一周，限流等待可解释、同步可恢复，不产生例句写入或整句翻译请求。
