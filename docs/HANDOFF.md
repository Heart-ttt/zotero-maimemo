# 交接：当前进度与待办

2026-10-05 更新。功能范围以 [SCOPE.md](SCOPE.md) 为准，架构说明见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 当前目标

在 Zotero 阅读器划选生词，确认加入本地队列，后台统一加入墨墨云词本「Zotero 背诵」和学习计划。只做 Zotero 和墨墨的联动，例句功能和阅读时提示在背词均已删除。

## 已完成

- 保留此前领域与应用服务，将阅读器、设置、宿主适配、持久化和后台调度分开实现。没有把 HTTP 写入放进 DOM 事件处理器。
- 通过 `renderTextSelectionPopup` 追加弹窗；多词选区一次选一个词，允许修改原形，点击加入才保存。具备重复点击防护、异步换词防过期覆盖和关闭清理。
- 注册「墨墨单词同步」设置页，支持 Token 保存、留空保留、清除、只读连接测试、学习计划开关，以及最近 50 条记录和手动重试。
- Token 使用 Zotero 凭据管理器的独立认证域，不写普通 prefs，不读取或修改 Zotero 同步凭据。历史提供的 Token 未预填、未写入源码或安装包。
- 单词队列使用 Zotero 数据目录的 JSON 文件原子替换，串行事务保证并发查重；重启恢复进度，损坏文件不覆盖，落盘失败不提交内存。
- 后台串行消费、临时错误退避、共享请求限速、429 冷却、401 暂停、配置变化时中止旧请求，禁用插件清理监听器、DOM、订阅和计时器。
- 修复云词本合并逻辑，保留章节、空行和缩进。学习计划改为先查单词 ID，再提交 `words: [{ id }]`；新增数不足时核对已有学习记录，不把未确认的结果标为成功。
- 补齐 manifest、bootstrap、esbuild 和 XPI 打包，产物在 `dist/zotero-wordsync-maimemo-0.1.0.xpi`，声明可安装于 Zotero 7–10（阅读器接口按 Zotero 10 实现）。阅读器弹窗和设置页已在本机 Zotero 10.0.5 安装验证。

41 项离线测试通过，覆盖领域、队列、存储、墨墨适配、DOM 交互、宿主替身和打包后的 bootstrap 加载；1 项真实墨墨只读集成测试默认跳过。原生验证确认双击正文会显示加入区，设置页能加载并显示配置项，点击加入会写入本地队列；本次未向墨墨账号执行写入。

此前使用用户 Token 完成过只读验证：认证有效；90 个样本词命中 73 个，常见词对照 10/10，找到「Zotero 背诵」。这些结果使用旧接口路径，不替代当前官方 `/api/v1/memo/*` 路径的验证。

## 后续工作

1. 在更多 Zotero 10.x 小版本和不同系统上复核 PDF 划词、多词选择、输入焦点、Esc、升级和禁用清理；本机 10.0.5 已通过。
2. 实测当前官方接口的只读解析和两步写入：云词本保留原文、重复词、未收录词、学习计划已存在或单词上限不足、App 自动同步的结果。写入探针与清理需要明确记录；只读脚本不得隐式改成写账号数据。
3. 实现可靠词形还原并确定词义来源；当前 `IdentityLemmatizer` 只是原词初值，不会自动将不同词形归并。
4. 实现待同步记录移除、清空和同步后撤销。已新增 `notepadAddedByPlugin` 字段，但远端已写入、本地保存前崩溃时仍可能无法确认归属，撤销不能据此误删已有词。
5. 继续处理词本并发修改冲突、跨重启频控记录与长时间限流等待提示，再完成 SCOPE 的完整 V1 验收。

Git 尚无首次提交；本次没有自动提交、安装到个人 Zotero 配置或修改账号数据。

## 接口依据

2026-10-05 读取墨墨官方 [OpenAPI YAML](https://open.maimemo.com/api_bundle.yaml)，当前文档将墨墨背单词路径标为 `/open/api/v1/memo/*`。学习计划参数为 `words: [{ id }]` 和 `advance`，成功响应的 `added_count` 可能因已存在或上限不足而减少。接口公测，仍需在 App 中开启自动同步。

官方频控为 10 秒 20 次、60 秒 40 次和 5 小时 2000 次。每天 600 条是例句、助记、释义创建的配额，当前项目不调用这些创建接口，不能当作每天最多加入 600 词。

本机 Zotero 10.0.5 源码确认阅读器钩子、设置注册、片段加载、原子文件写入及凭据管理 API。其他 Zotero 主版本没有兼容声明。

历史调研和验证脚本仍保留：`scripts/verify-maimemo.sh` 的 `auth`、`coverage`、`study` 是只读检查；脚本和历史 API 文档使用旧路径。原始响应在被忽略的 `out/`，不进入源码或安装包。
